1. Manage Users in Solution Provider Portal

Источник: manage-users-in-spp

Learn how to add employees to your Solution Provider Portal account, manage permissions, delegate client access, and remove users when needed.

As an SP-API developer or service provider, you might need to give multiple employees access to your company's Solution Provider Portal account so that your employees can help manage your SP-API applications and client relationships. Multi-user access is particularly common for service provider companies.

Add Employees to Your Account

To add an employee to your Solution Provider Portal account:

  1. Sign in as an admin.
  2. Choose Services > Permissions Management.
  3. Choose Global Account Permissions > Add User.
  4. Enter the user's name and email.
  5. Choose Send Invite.
Important: Use the employee's Seller Central email address, if available, or request their preferred email address. This will be their sign-in email for Solution Provider Portal and future Seller Central access.

Manage Employee Permissions

To grant permissions:

  1. Sign in as an admin.
  2. Choose Services > Permissions Management > Global Account Permissions.
  3. Next to the employee's name, choose Manage Rights.
  4. Select permissions to grant. Ensure Global Account is selected.
  5. Save changes.

Grant Admin Permissions

To grant admin-level permissions:

  1. Sign in as an admin.
  2. Choose Settings > User Permissions > Global User Permissions.
  3. Next to the employee's name, choose Manage Rights.
  4. Select Global Account.
  5. Grant admin permissions (e.g., Manage Clients, Manage Global User Permissions).
  6. Save changes.

Delegate Client Access

To assign seller accounts to employees:

  1. Sign in as an admin or primary user.
  2. Choose Services > Permissions Management > Global Account Permissions.
  3. Search for the employee.
  4. Choose Add user to client, select the seller account, and submit.
  5. Assign permissions via Manage Rights for the client.

View Access and Assignments

  • To review users with access to a seller account: Navigate to Global Account Permissions > Clients > search the seller.
  • To view a user's assigned sellers: Go to User Permissions > Global User Permissions > Manage Rights for the user.

Manage Client Access

  • Remove client access from an employee: Use Remove Access From Account in User Permissions.
  • Remove a seller from your account: Navigate to Clients > Remove from this account.

Remove Employees

To remove an employee:

  1. Sign in as an admin.
  2. Choose Settings > User Permissions > Global User Permissions.
  3. Select the employee and choose Remove User.

Accept Invitations (For Employees)

  1. Use the email in the invitation to sign in or create a new account in Solution Provider Portal.
  2. Choose Accept Invitation.

Access Assigned Sellers

To access seller accounts:

  1. Sign in to Seller Central using the email registered with Solution Provider Portal.
  2. Select your service provider's global account to view assigned sellers.
  3. Choose the seller to access their account with granted permissions.

Troubleshooting Invitation Issues

If an employee uses a different email:

  1. The admin receives a notification and must approve the registration.
  2. Admin selects Confirm Invitation in Open Invitations to finalize.

2. Manage Your Business And Contact Information in Solution Provider Portal

Источник: update-business-contact-information-in-spp

Learn how to manage your business and contact information in Solution Provider Portal.

This guide shows you how to update business and contact information. Required after identity verification is complete.

Important: Only the administrator of the Solution Provider Portal account can perform these steps.

Prerequisites

  • Solution Provider Portal account established
  • Identity verification completed

Update Your Business Information

  1. Sign in to Solution Provider Portal.
  2. Select your account and choose Select Account.
  3. Click the gear icon at the top.
  4. Choose Account Info → Business information.
  5. Business Name Format Requirements: Complete legal name, include DBAs/trade names, original language spelling if applicable.
  6. Enter Company Registration Number.
  7. Provide Registered Business Address.
  8. Verify and complete phone number authentication.

Update Your Business Contact Information

  1. Sign in to Solution Provider Portal.
  2. Select your account and choose Select Account.
  3. Navigate to Business & Contact Info section.
  4. Business Name Requirements: Complete legal name with DBAs/trade names.
  5. Website URL Requirements: Complete address; verify website is live.
  6. Home Country: Enter legal registration country.
  7. Primary Contact Name: Full first and last name with optional language spelling.
  8. Email Address: Use business email, ensure active monitoring, verify correctness.
  9. Phone Number: Include complete business phone with area code.
  10. Select Save.

3. Manage Billing Information in Solution Provider Portal

Источник: manage-billing-information-in-solution-provider-portal

Add, edit, and manage credit card and debit card billing information in Solution Provider Portal.

This guide shows you how to add and manage credit cards and debit cards in Solution Provider Portal. Learn how to add new cards, view your existing cards, edit card details, switch cards, and remove cards from your account.

For information about SP-API fees, refer to An Update on SP-API Fees and Understanding SP-API Metered and Unmetered Calls.

Note: You must retain at least one valid credit card or debit card on file to maintain SP-API access and to continue offering apps in the Solution Provider Appstore.
Important: Only the administrator of the Solution Provider Portal account can perform these steps.

Prerequisites

  • A Solution Provider Portal account
  • Valid credit card or debit card information

Add a New Credit Card or Debit Card

  1. Sign in to Solution Provider Portal.
  2. Choose your account, and then choose Select Account.
  3. At the top, choose the gear icon, choose Payments, and then choose Charge Methods.
  4. Choose Add new charge method.
  5. Enter the following information:
    • Card number
    • Cardholder name
    • Expiration date
    • Business address
  6. Choose Set Charge Method.

After registering your payment method, the homepage displays your API usage summary.

View Existing Credit Cards and Debit Cards

  1. Sign in to Solution Provider Portal.
  2. Choose your account, and then choose Select Account.
  3. At the top, choose the gear icon, choose Payments, and then choose Charge Methods.
  4. Choose Manage Charge Method.

For each card, you see the following information:

  • Masked card number (ending in the last four digits)
  • Cardholder name
  • Expiration date

Edit Credit Card or Debit Card Information

  1. Sign in to Solution Provider Portal.
  2. Choose your account, and then choose Select Account.
  3. At the top, choose the gear icon, choose Payments, and then choose Charge Methods.
  4. Choose Manage Charge Method.
  5. Select the card to edit.
  6. Update any of the following information:
    • Cardholder name
    • Business address
  7. Choose Submit.

Switch Credit Cards or Debit Cards

  1. Sign in to Solution Provider Portal.
  2. Choose your account, and then choose Select Account.
  3. At the top, choose the gear icon, choose Payments, and then choose Charge Methods.
  4. Choose Replace Card.
  5. Select the card to use.
  6. Verify that the selected card is now active.
Note: You must have at least one valid credit card or debit card in your account.

Delete a Credit Card or Debit Card

  1. Sign in to Solution Provider Portal.
  2. Choose your account, and then choose Select Account.
  3. At the top, choose the gear icon, choose Payments, and then choose Charge Methods.
  4. Select the card to delete.
  5. Choose Delete.
  6. Confirm the deletion.

4. Manage Tax Registration Information in Solution Provider Portal

Источник: manage-tax-registration-information-in-solution-provider-portal

Add and manage tax registration information in Solution Provider Portal.

This guide shows you how to add and update tax registration information in Solution Provider Portal. Learn how to add new tax registration numbers, edit your existing information, add or update addresses, and remove registrations from your account.

Tax registration requirements vary by country. For details, refer to Tax Registration Agreement.

For information about SP-API fees, refer to An Update on SP-API Fees and Understanding SP-API Metered and Unmetered Calls.

Important: Only the administrator of the Solution Provider Portal account can perform these steps.

Prerequisites

  • A Solution Provider Portal account
  • Valid tax registration information for your country

Add a Tax Registration Number

  1. Sign in to Solution Provider Portal.
  2. Choose your account, then select Select Account.
  3. Navigate to the tax registration information.
  4. Choose Add a VAT/GST registration number.
  5. Select your country from the dropdown list:
    • United States or Mexico: No additional information required.
    • Other countries: Complete the tax registration form with your details.
  6. Choose Add number.

Edit Tax Registration Information

  1. Sign in to Solution Provider Portal.
  2. Choose your account, then select Select Account.
  3. Navigate to the tax registration information.
  4. Locate the tax registration to edit.
  5. Choose Edit.
  6. Update the registration details.
  7. Choose Edit to save changes.

Add a Tax Registration Address

  1. Sign in to Solution Provider Portal.
  2. Choose your account, then select Select Account.
  3. Navigate to the tax registration information.
  4. Choose Edit for the relevant tax registration.
  5. Choose Add a new address.
  6. Enter the new address details.
  7. Choose Edit to save.

Update a Tax Registration Address

  1. Sign in to Solution Provider Portal.
  2. Choose your account, then select Select Account.
  3. Navigate to the tax registration information.
  4. Choose Edit for the relevant tax registration.
  5. Select a different address from available options.
  6. Choose Edit to save.

Remove a Tax Registration Number

  1. Sign in to Solution Provider Portal.
  2. Choose your account, then select Select Account.
  3. Navigate to the tax registration information.
  4. Choose Edit for the registration to remove.
  5. Choose Delete.
  6. Confirm the deletion.

Troubleshooting: Invalid VAT/GST Registration Number

  • Validate your number: Use the VIES VAT validation tool or Check a UK VAT number site.
  • Check for errors: Look for typos, extra spaces, or missing characters.
  • Use the country prefix: Example: GB123456789
  • Japanese developers: Use your Japanese Consumption Tax ID with a T prefix (e.g., T1234567890123).

For more information, contact your tax advisor.

6. Unify Your Developer Accounts

Источник: spp-account-unification

Learn how to unify all of your developer accounts in Solution Provider Portal.

Solution Provider Portal is replacing Developer Central as the central gateway for managing your Amazon developer offerings. This guide explains how to merge your existing developer accounts into Solution Provider Portal.

For a video about account unification, refer to How to Migrate and Unify Your Amazon Developer Accounts to Solution Provider Portal.

Key Points About Account Unification

  • Your existing developer profiles are located in Developer Central, Seller Central, or Vendor Central.
  • Solution Provider Portal replaces Developer Central. Seller Central and Vendor Central remain active.
  • Account unification is irreversible.
  • The account unification process takes up to 10 minutes.

Single Profile Migration

Scenario: You use one email address to sign in to Seller Central, Vendor Central, or Developer Central. Your account has one active developer profile.

Steps:

  1. Sign in to Solution Provider Portal with your existing email and password.
  2. Review your developer profile information (apps, contact info, permissions, etc.). Contact Developer Support if data is incorrect.
  3. Choose Confirm & Continue. Verify if additional accounts exist and choose Continue.
  4. Wait 10 minutes for profile creation and choose Proceed now.

Profile Consolidation

Scenario: You have one email address with two or more active profiles.

Steps:

  1. Sign in to Solution Provider Portal. Review your profile data.
  2. Choose Authenticate another email to add an additional account.
  3. Confirm profiles to merge and specify a new profile name/email.
  4. Wait 10 minutes and choose Proceed now.

Profile Distribution

Scenario: You use multiple emails for Seller/Vendor Central and want multiple Solution Provider Portal profiles.

Steps:

  1. Sign in and authenticate additional emails.
  2. Name your new profile and choose I'd like to create multiple profiles.
  3. Create profiles using Create another new SPP profile and assign existing profiles.
  4. Confirm all active profiles are assigned and wait 10 minutes.

Large-Scale Unification (15+ Profiles)

Scenario: You have more than 15 active profiles.

Steps:

  1. Sign in. If prompted, request support via Seller/Vendor Central help pages for assistance with merging.
  2. If choosing self-service, follow steps from Profile Distribution.

Troubleshooting

  • Publishing pipeline issues: Profile creation delays may occur. Amazon will handle merges manually if needed.
  • Failed merge: Retrying is allowed. Contact support for persistent issues.
  • Failed unification: Look for errors in your Solution Provider Portal homepage.

7. Verify Your Identity in Solution Provider Portal

Источник: verify-identity-in-spp

Learn how to verify your identity in Solution Provider Portal.

All Solution Provider Portal users, including developers, service providers, and invited employees, must verify their identity regardless of their role or access level within the organization. This guide shows you how to complete the identity verification process in Solution Provider Portal.

Amazon requires at least two documents: an identity document and a proof of address document.

Identity Document Requirements

  • Government-issued photo ID (passport, national ID, driver's license)
  • Recognized by the country of citizenship/residence
  • Includes full name, date of birth, unique ID number
  • Expiration date (or 3-month future date if absent)
  • Signature if applicable
  • Full information from both sides of the ID (e.g., signature, barcodes)
  • Color scan/photograph

Proof of Address Requirements

  • Valid for 180 days with issuing date
  • Includes financial institution details (bank name/logo/signature)
  • Account holder's name and address

Accepted types: Bank statements, credit card statements, e-commerce payment service provider (Payoneer/Hyperwallet/World First/Alipay) account statements

Steps to Verify Identity

  1. Sign in to Solution Provider Portal.
  2. Select Get Started and complete the business information form.
  3. Choose SMS or Phone for Receive PIN Through, validate with CAPTCHA and phone number.
  4. Enter the received PIN and select Verify.
  5. Complete the primary contact person form and review details.
  6. Upload:
    • 1 identity document
    • 1 proof of address
  7. Proceed to identity verification form:
    • Select verification option
    • Confirm Start Identity Check
Warning: Ensure all details match documents exactly. Edits are not allowed after submission.

Post-Verification Actions

  • Monitor on-screen confirmation and email for results within 2 business days.
  • Upon success, complete:
    • Developer profile form (SP-API access)
    • Service provider profile form

Frequently Asked Questions

Why verify employees if the admin is already verified?

Amazon requires all users to verify identities to secure sensitive business data.

Can denied applications be appealed?

No. Verification decisions are final.

Is information editable after submission?

No. Review carefully before submitting.

Can I save the form for later completion?

Yes. Progress is automatically saved after each page.

8. API Usage Metrics in Solution Provider Portal

Источник: api-usage-metrics-in-spp

View your application performance, API call volume, error rates, and usage metrics in Solution Provider Portal.

The API usage dashboard in Solution Provider Portal helps you monitor performance across your registered applications. Use the dashboard to:

  • Track error rates: Monitor client error percentages to identify potential issues with your API implementations.
  • Analyze call patterns: Review call volume trends to understand usage patterns.
  • Identify problem operations: Use the detailed breakdown to pinpoint specific API operations that might need attention.

You can view metrics at the account level, filter by application, and filter by time frame.

Note: Dashboard data is refreshed daily and shows the last update timestamp at the top of the page.

Accessing the API Usage Dashboard

Within Solution Provider Portal, you can access the API usage dashboard in two ways:

  1. From the main page: In the featured functions section, choose Manage API calls.
  2. From the navigation menu: Choose Apps, and then choose API Usage Dashboard.

Filtering Data

Customize the dashboard display using these filters:

  • Application filter: Choose All Apps to view data for all applications or select a specific application from the dropdown.
  • Time frame filter: Choose your desired time period (e.g., "This month").

Available Metrics

Account-Level Summary

The account-level summary provides an overview of your account's performance metrics:

  • Apps - Number of applications registered in your account
  • Call volume - Total number of API calls across all applications
  • Successful calls - Number of successful API calls
  • Successful call rate - Percentage of successful calls
  • Client errors - Number of client error responses
  • Client error rate - Percentage of client error responses

Application-Level Details

For each registered application, the dashboard shows a detailed breakdown table with:

  • Section - API section names (e.g., fba, dataKiosk, feeds, orders)
  • Operation - Specific API endpoints and operations
  • Call Volume - Total number of calls for each operation
  • HTTP Status Codes - Response code distribution:
    • Successful calls (200, 201, 202, 204)
    • Client errors (400, 403, 404, 429)
    • Server errors (500)
